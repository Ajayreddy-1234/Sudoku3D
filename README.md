# 3D 4×4 Sudoku Puzzle in Unity

A push-and-pull block–based 3D Sudoku game built in Unity, featuring third-person exploration, dynamic camera switching, procedurally generated puzzles, and intuitive grid-aligned movement.

## 🎮 Features

- **4×4 Sudoku Mechanics**  
  - Fully valid 4×4 Sudoku generated at runtime  
  - Random prefilled cells with no conflicts  
  - Supply-zones that auto-refill blocks when you push/pull  

- **Block-Pushing & Pulling**  
  - Face a numbered block and press **W** to push it one tile forward  
  - Press **S** to pull a block toward you (if there’s space behind)  

- **Grid-Aligned Movement**  
  - Move or interact one tile at a time  
  - Rotate in 90° increments with **A** (left) / **D** (right)  

- **Dual-Camera System**  
  - **Top-Down View** for planning (toggle with **V**)  
  - **Third-Person View** for movement and interaction  
  - Camera collision avoidance keeps walls and blocks from clipping  

- **UI & Screens**  
  - Start menu with character and block background  
  - In-game timer and controls overlay  
  - Victory end screen displaying time and options to replay or return to menu

## 🕹 Controls

| Key | Action                           |
|:---:|:---------------------------------|
| W   | Move forward / push block        |
| A   | Turn left 90°                    |
| D   | Turn right 90°                   |
| S   | Pull block toward player         |
| V   | Toggle camera (Top-Down / TPP)   |

> **Note:** Player movement & block interaction only work in Third-Person View (TPP).
